# 물특 — 어항 등록·표시·돌봄 개선본

## 이번 수정
- 도감 등록 화면에서 +/-로 마릿수 조절, 최초 등록 시 같은 화면에서 수조 용량 입력
- 기존 기록을 기반으로 어종 ID/마릿수 구조화 저장(`multeuk_tank_species_v1`), 기존 기록 자동 인식
- 실제 등록한 어종의 기존 일러스트 PNG를 메인 '내 꾸미기 어항'에 표시 (실제 마릿수는 텍스트로, 한 종의 애니메이션은 최대 4개)
- 메인 어항과 일기에서 등록 어종 확인/삭제, 도감에서 수량 수정
- 하단 모바일 빠른 메뉴
- 오늘의 돌봄에서 등록 어종별 정보 표시, 어종 미등록이면 급여/환수 업무 숨김, 매일 항목은 날짜 변경 시 체크 해제
- 관찰일지의 수온·물맑기·먹이 반응은 미측정 상태를 기본값으로 사용
- 백업 포맷 v2에 구조화된 어종 목록 포함, 기존 v1 백업도 복원 가능
- 이전 Render 배포 성공에 사용한 Vite 7 / React 플러그인 5 버전 반영

## 반영 방법 (GitHub 웹사이트)
저장소: `wndus01113-lab/multeuk_AI`

1. GitHub 저장소의 최상위(`multeuk_AI`)에서 `Add file → Upload files`.
2. `교체할_파일만` 압축을 해제한 **`multeuk-ai` 폴더를 그대로** 끌어다 놓으세요. 경로가 `multeuk-ai/src/App.tsx` 등으로 보이는지 확인하세요.
3. 변경 파일들을 모두 확인한 후 `Commit changes`. Render의 GitHub 자동배포가 켜져 있으면 새 커밋 배포가 시작됩니다. 아니면 `Manual Deploy → Deploy latest commit`.
4. 기존 데이터가 중요한 기기는 배포 전 `어항 일기 → 백업 내려받기`로 백업합니다.

### 주의
- 가상 어항의 시각화는 실제 수조 상태 측정값이 아닙니다. 표시된 물고기 수와 실제 사육 적합성은 별개입니다.
- 저장은 동일 브라우저의 localStorage에 유지됩니다. 다른 기기로 자동 공유되지는 않으며 브라우저 데이터 삭제 시 사라질 수 있습니다. 백업 사용 권장.
- JSON 복원은 등록 어종 정보를 포함합니다(v2).
- 테스트는 TypeScript/TSX 문법 검사 및 12종 이미지 존재 확인까지 수행했습니다. 패키지 다운로드 제한으로 실제 npm build/브라우저 테스트는 이 환경에서 마치지 못했습니다.
