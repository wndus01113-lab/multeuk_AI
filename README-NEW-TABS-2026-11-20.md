# 물특 PC·모바일 탭 개편 (2026-11-20)

## 화면
- 홈 / 물고기 도감 / AI 물방울 / 돌봄 일기 / 관상어 배지 / 초보 백과를 **독립 탭**으로 구성. 주소는 `#home`, `#dex`, `#ai`, `#care`, `#badges`, `#guide`.
- 데스크톱: 상단 내비게이션, 다단 카드. 모바일: 하단 고정 메뉴(5개) + 초보 백과는 홈에서 진입.
- 홈의 첫 시작 선택: 키우고 싶은 사람은 도감, 처음 키우는 사람은 돌봄.
- 도감에서 어종 등록·어항 등록 기능 제거. 12종 로컬 PNG 유지.
- 수족관 꾸미기/장식 해금 기능 화면에서 제거. 어종 등록에 따른 애니메이션 어항도 홈에서 제거.
- 보상: 기존 도감 일러스트와 물특 색감을 조합한 배지 7종. 현재 브라우저의 기록·학습 여부 기반.
- AI: 긴 답변을 유도하는 서버 프롬프트 축소(기본 3~5문장 권장, 안전 문제 예외), 스트리밍 때 강제 자동 스크롤 제거.
- 돌봄: '키우기 전/이미 키우는 중' 선택, 실제 관찰일기만 기록, 수온·수질 기본값 미측정, 기록 JSON 백업 다운로드.
- 기존 브라우저 로컬 스토리지의 돌봄 작업/관찰일기 유지. 레거시 어항 프로필 정보는 삭제하지 않지만 새 UI에는 노출하지 않음.

## 배포
1. `물특-탭개편-전체코드.zip`을 압축 해제.
2. **GitHub 저장소 루트**의 `multeuk-ai/` 폴더와 동일한 경로를 유지해 업로드하고 기존 파일을 교체. 루트에 `multeuk-ai/multeuk-ai/` 이중 폴더가 생기면 Render가 실패하니 반드시 확인.
3. Render 자동 배포가 완료되면 홈→도감→AI→돌봄→배지, 모바일 순으로 검증.

## 검사와 제한
- TypeScript/TSX 소스의 문법 검사, 내부 import 경로, 이미지 자산 존재, ZIP 무결성 확인.
- 이 실행 환경에서는 npm 패키지 설치가 네트워크 문제로 완료되지 않아 실제 `npm run build`와 브라우저 테스트는 미실시. Render 로그와 실제 기기에서 추가 점검 필요.
- 사이트는 계정이 없는 로컬 저장 방식이므로 기기 간 자동 동기화 없음.
