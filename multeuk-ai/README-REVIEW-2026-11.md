# 물특 도감·안전성·모바일 개선 기록 (2026-11)

## 이미지 라이선스
- `src/data/fishPhotos.json`에 12종 이미지의 Wikimedia Commons 원본 파일 페이지, 저작자, Creative Commons 라이선스 링크를 명시했습니다.
- 이미지 파일 자체는 재배포하지 않고 Wikimedia Commons `Special:FilePath`에서 불러옵니다. 네트워크 또는 핫링크 제한 시 이모지 대체 표시됩니다.
- 카드 상세 화면에서 저작자·라이선스·원본 링크를 제공하며 사진을 변형하지 않았습니다.
- Wikimedia Commons의 라이선스 표시는 원본 페이지를 기준으로 확인했습니다. 사진 실물 로딩은 이 실행 환경에서 확인하지 못했습니다.
- 라이선스 CC BY-SA를 따르는 사진을 변경·재배포한다면 동일조건변경허락 등 추가 의무를 검토하십시오.

## 사육 정보
- 기존 데이터는 출처 없는 '검증 기준'으로 표시되어 있고 소형 어항을 지나치게 허용한 사례가 있어 수정했습니다.
- `verifiedFishKnowledge.json`에는 어종별 참고 링크가 있습니다. 주로 Seriously Fish의 종별 프로필 및 RSPCA의 어항 기본 지침과 대조했으며, 수치가 서로 다른 경우 보수적으로 수조 바닥 면적 및 군영/번식 조건을 강조했습니다.
- 코리도라스·안시·금붕어 등 종/품종을 통칭하는 항목은 단일 일괄 기준을 보장할 수 없습니다.
- 체리새우와 야마토새우를 동일 종으로 다루던 동의어를 제거했습니다.
- 어떤 경우에도 도감과 AI 답변은 수의학적 진료나 수질 시험을 대신하지 않습니다.

## 핵심 수정
1. 도감 12종의 실제 Commons 사진 링크 및 화면상 저작자/라이선스 표기
2. 도감에서 마릿수 입력 → 내 어항 기록. 단 어항 L 미입력 시 등록 방지, 적합성은 승인하지 않음
3. 잘못된 Gemini 예비 모델 ID 제거 및 서버 환경변수 `GEMINI_MODEL` 사용 가능
4. 서버 API 기본 IP별 1분 18회 제한, 이미지·텍스트 요청 크기 확인, Express 서버 정보 헤더 제거
5. 배포 실행 `tsx server.ts`로 통일, tsx를 production dependency로 이동
6. 모바일 도감 모달 safe-area·스크롤, AI 허브 탭 가로 스크롤, 입력 포커스 확대 방지

## 남은 검증 사항
- 실제 `npm install`, `npm run lint`, `npm run build`, API 연결, 모바일 Safari/Chrome 실기기 테스트는 환경에 따라 재확인 필요.
- 서버 rate limit은 단일 프로세스 메모리 기반으로 여러 인스턴스/재시작 간 공유되지 않음. 공개 서비스 확대 시 외부 제한기 필수.
- 현재 어항 정보 저장은 사용자 브라우저(localStorage)에만 남으며 기기 간 동기화는 안 됨.
- 도감 등록은 기록 작업일 뿐, 합사나 마릿수 안전성을 자동 심사하지 않음.
