# 물특 필수 수정 5개 — 2026-11-18

이 폴더는 기존 `물특-AI-도감사진-검증-모바일개선본.zip` 위에 5가지 수정을 적용한 버전입니다. 기존 저장 키는 변경하지 않았습니다.

1. **중복 어종 등록**: 도감에서 같은 종을 등록하면 새 항목을 이어붙이지 않고 해당 종의 마릿수를 교체합니다. `0`마리는 해당 종을 목록에서 삭제합니다. 기존 수기 작성 데이터는 가능한 유지합니다.
2. **사육 부적합 경고**: 도감에 표기된 리터 수 최소 기준에 미달하면 경고, 길이(cm) 기준은 수량만으로 충족 판단을 하지 않는 경고를 보입니다. 기존 합사·사육량은 자동으로 승인하지 않고 모든 등록 전에 재확인 단계를 둡니다. 이 기능은 *사육 적합성 판정 엔진이 아닙니다.*
3. **AI 요청 제한**: 단일 프로세스에서는 분당 IP 18회 제한. `UPSTASH_REDIS_REST_URL`, `UPSTASH_REDIS_REST_TOKEN` 두 환경변수를 함께 설정하면 여러 서버 간 IP 18회/분 + 전체 350회/분 제한을 공유합니다. Redis가 실패하면 AI 요청을 503으로 거절해 무제한 요청으로 우회하지 못하게 합니다. Redis 미설정 시 다중 서버/재시작 사이 제한은 공유되지 않으므로 공개 대규모 배포 전 설정 필요. Render에서 `trust proxy=1`을 설정합니다.
4. **사진 연결 오류**: 외부 Commons 원본이 차단·삭제되면 어종 아이콘을 보여주고 원본 페이지 열기/사진 재시도 버튼을 제공합니다. 사진은 외부 원본 주소를 사용하기 때문에 네트워크 없이 100% 표시되는 상태는 아닙니다. 재배포 전 개별 라이선스와 URL을 확인하고, 허용되는 사진을 프로젝트에 로컬 포함하는 것을 권장합니다. **사진 파일을 직접 저장한 것은 아닙니다.**
5. **기록 백업/복원**: 어항 일기 → 내 어항 정보에서 JSON 다운로드/불러오기를 제공합니다. 어항 프로필·관찰일지·체크리스트·꾸미기·사용자 규칙·답변 설명 모드를 포함합니다. 불러올 때 크기·파일 형식·기본 구조를 검증하고 사용자에게 덮어쓰기 확인을 받습니다. 복원은 브라우저 내부 기록을 교체하므로 반드시 기존 기록을 먼저 백업할 것을 권장합니다.

## 검사 결과
- TypeScript/TSX 19개 파일 transpile 문법 검사 통과.
- 이 실행 환경에는 npm 패키지를 내려받을 네트워크가 없어 `npm install`, `npm run lint`, `npm run build`, 모바일 Safari 및 Gemini API 실제 실행 테스트는 수행하지 못했습니다.
- 정적 코드 검사 통과는 실제 동작 보증이 아닙니다.

## 배포 안내
```
npm install
npm run lint
npm run build
npm start
```
운영에서는 `GEMINI_API_KEY`를 비밀 환경변수로 설정하고, 다중 인스턴스나 공개 서비스에서는 Upstash Redis 공유 제한 설정을 권장합니다.
