# 물특 — AI 관상어 도우미 🐠

학생 프로젝트 물뚝을 **물특**으로 리브랜딩한 버전입니다. 원본 주요 기능(입문 어종 추천 / 수조 사진 관제 / AI 상담 / 사용자 규칙 / 어항 일기 / 돌봄 체크리스트 / 꾸미기 보상)을 유지했습니다.

- 마스코트: 사용자 제공 물방울 그림, `src/assets/images/multeuk_mascot.webp`
- 메뉴: AI 도우미 · 오늘의 돌봄 · 어항 일기 · 초보 백과
- 처음 보이는 어항: 꾸미기 일러스트 화면. '맑은 수족관' 사진 보기로 전환 가능
- 기존 저장 데이터 호환성을 위해 `multtuk_...` localStorage 키는 유지

## 배포

Node.js 22.18 이상 사용. `npm install`, `npm run build`, `npm start` (운영 환경: `NODE_ENV=production`, 호스팅 서비스가 제공하는 `PORT`). `GEMINI_API_KEY`는 **서버 환경변수**로만 설정하고 소스 저장소에 넣지 마세요. 공개 배포 전 API 호출량 제한과 Gemini 과금/할당량을 점검하세요.

> GitHub의 기존 저장소는 자동으로 수정되지 않았습니다. 이 ZIP을 새 브랜치나 저장소에 업로드한 후 배포해야 합니다.

## 🐠 12종 물고기 도감 (추가)
- 상단 메뉴 '물고기 도감' (모바일 빠른 메뉴 포함) → 검색·분류·상세 정보
- 원본 `src/data/verifiedFishKnowledge.json`의 12개 항목을 직접 참조 (어류 11종 + 관상새우 1종)
- 카드를 누르면 수온, pH, 원본 최소 수조 기준, 성격, 합사 참고 및 주의, 사육 메모 표시
- 상세 화면의 '물방울에게 이 친구 물어보기'는 기존 AI 상담 흐름에 연결
- 표기된 이모지는 실제 어종 사진이 아닌 장식용 아이콘입니다.
- 주의: 지식 베이스의 어종별 근거 문헌이 기재되지 않아 수치/합사 정보는 독립 검증하지 않았습니다. 초보자 안전 안내를 넣었습니다.
